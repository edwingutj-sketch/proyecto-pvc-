Proyecto escolar de cancelería sustentable

Prototipo de cancelería con PVC reciclado

Una maqueta escolar hecha con piezas de PVC recuperado, técnica de laminado, planchado controlado, prensado artesanal, lijado y acrílico como simulación del vidrio.

Ver proceso Justificación científica

Idea central

Reciclar, transformar y demostrar

Este proyecto escolar busca demostrar que el PVC recuperado puede transformarse en piezas tipo perfil para una maqueta de cancelería. El objetivo no es fabricar una ventana real lista para instalarse, sino comprobar una idea técnica y ambiental usando herramientas accesibles.

El prototipo se realizó con una técnica artesanal de laminado: se cortaron piezas de PVC, se acomodaron por capas, se calentaron con plancha, se prensaron, se lijaron y se ensamblaron para formar un marco. Para simular el vidrio se utilizó acrílico.

Marco histórico

Origen e importancia del PVC

El PVC, o policloruro de vinilo, es uno de los plásticos más usados en el mundo. Fue descubierto en el siglo XIX, pero su uso comercial creció cuando se logró hacerlo más procesable y útil para aplicaciones industriales. En el siglo XX comenzó a utilizarse en cables, recubrimientos, tuberías, pisos y perfiles.

En construcción, el PVC rígido se volvió importante porque resiste humedad, no se oxida, es ligero y puede fabricarse en formas largas como tuberías o perfiles. Por eso resulta interesante para un proyecto escolar de cancelería sustentable.

Problema ambiental

PVC y residuos de construcción

Muchos residuos de construcción y demolición terminan mezclados con cemento, tierra, madera, vidrio, metal y plásticos. Cuando el PVC se desecha sin separación, puede terminar en tiraderos o contaminar otros materiales reciclables.

Recuperar PVC limpio permite darle una segunda vida. En este proyecto, el material no se funde industrialmente; se trabaja como prototipo escolar mediante corte, calentamiento controlado, presión, lijado y ensamble.

Propiedades

Qué es el PVC y por qué sirve

Ventajas

  • Resiste humedad y corrosión.
  • Es ligero y fácil de transportar.
  • Puede cortarse, lijarse y moldearse con herramientas básicas.
  • Funciona bien para piezas rígidas.
  • Puede reutilizarse si está limpio y separado.

Desventajas

  • No debe quemarse ni sobrecalentarse.
  • Puede liberar vapores irritantes si se degrada.
  • El reciclado puede tener suciedad o impurezas.
  • La resistencia cambia según el origen del residuo.
  • El acabado artesanal requiere mucho lijado y cuidado.

Proceso escolar

Cómo se fabricó el prototipo

  1. Recolección. Se juntaron piezas de PVC recuperado, principalmente tubos y sobrantes.
  2. Corte. Las piezas se cortaron en tiras para poder trabajarlas como láminas.
  3. Laminado. Las tiras se acomodaron por capas para formar piezas más gruesas.
  4. Planchado controlado. Antes de prensar, el PVC se calentó con una plancha para ablandarlo y facilitar que las capas se adaptaran a la forma deseada.
  5. Prensado. Después del calentamiento, se usaron madera, tornillos y prensas para mantener presión durante el armado.
  6. Lijado. Se corrigieron bordes, marcas e irregularidades.
  7. Ensamble. Se formó un marco con cortes en ángulo.
  8. Acrílico. Se colocó una lámina translúcida para simular el vidrio.
  9. Acabado. Se aplicó pintura para mejorar la presentación final.

Por qué se planchó el material

El PVC rígido no se derrite como cera, pero al calentarse de forma controlada puede ablandarse. Esto permitió que las tiras se acomodaran mejor antes del prensado.

La plancha funcionó como una herramienta escolar para aplicar calor directo. Después, la presión ayudó a mantener las capas alineadas mientras el material se enfriaba.

Este paso debe hacerse con mucha precaución: el PVC no debe quemarse ni producir humo, porque al degradarse puede liberar vapores irritantes.

Acrílico

Sustituto escolar del vidrio

Lámina transparente

El acrílico permite simular el vidrio sin trabajar con vidrio real.

Por qué se usó acrílico

Para una maqueta escolar es más seguro, ligero y fácil de cortar que el vidrio. No tiene la misma resistencia ni acabado profesional que una ventana real, pero funciona bien para representar la parte transparente del prototipo.

Justificación científica

Química, calor y resistencia del prototipo

Explicación química

El PVC está formado por cadenas largas de polímero llamadas policloruro de vinilo. Cuando se calienta moderadamente, el material puede ablandarse porque aumenta el movimiento de sus cadenas. Por eso fue posible darle forma con plancha y después mantenerla con presión.

Si el PVC se sobrecalienta, puede iniciar una degradación llamada deshidrocloración, donde se libera ácido clorhídrico. Por eso el proyecto debe trabajar siempre sin humo, sin flama directa y con ventilación.

Idea clave

El proyecto aprovecha un cambio físico controlado: el PVC se ablanda con calor y luego recupera rigidez al enfriarse. No se busca quemarlo ni descomponerlo químicamente.

Lo que se buscó en el prototipo

En el proyecto se aprovechó principalmente un cambio físico: el PVC se ablandó con la plancha, se acomodó por capas y después recuperó rigidez al enfriarse dentro de la prensa.

Lo que se debe evitar

No se debe quemar el PVC ni permitir que produzca humo. El humo o el olor fuerte indican que el material puede estar degradándose, lo cual representa un riesgo para la salud.

Resistencia hipotética

Cómo se podría comprobar

Prueba escolar Qué mide Resultado esperado
Flexión manual Si el perfil se dobla o se rompe al aplicar fuerza. El laminado debería resistir mejor que una sola tira delgada.
Carga con peso Cuánto peso soporta el perfil antes de deformarse. Más capas y mejor prensado deberían aumentar la rigidez.
Golpe ligero controlado Resistencia al impacto accidental. El PVC puede resistir golpes moderados, pero las uniones son el punto débil.
Exposición al sol Si cambia color, forma o rigidez. Puede amarillear o deformarse si el acabado no protege bien.
Revisión de uniones Si las capas se separan. La presión, el lijado y el adhesivo influyen mucho en la resistencia.
Hipótesis: a mayor número de capas + mejor presión + mejor alineación, mayor rigidez del perfil.

Científicamente, la parte más importante del prototipo no es solo que se vea como una ventana, sino comprobar si el método de laminado mejora la resistencia frente a piezas sueltas de PVC. Para una versión escolar, bastaría comparar una tira individual contra una pieza laminada usando el mismo peso o la misma fuerza.

Seguridad

Precauciones importantes

El PVC no debe quemarse ni sobrecalentarse. Durante el corte, planchado, lijado, aplicación de pintura o uso de adhesivos, se debe trabajar con ventilación y protección.

  • Usar lentes de seguridad.
  • Usar guantes al cortar, calentar o lijar.
  • Evitar inhalar polvo de lijado.
  • No usar fuego directo sobre el PVC.
  • Suspender el calentamiento si aparece humo u olor fuerte.
  • Aplicar pintura y adhesivos en un lugar ventilado.

Conclusión

Viable como proyecto escolar

El prototipo demuestra que el PVC recuperado puede reutilizarse para crear una maqueta de cancelería. La técnica de laminado, apoyada con planchado controlado y prensado artesanal, permite formar piezas tipo perfil con recursos accesibles. Aunque no sustituye a una ventana profesional, sí funciona como proyecto escolar ambiental, técnico y creativo.
